1. Introducción a CSS

El lenguaje CSS (Cascading Style Sheets) es el código que utilizamos para darle estilo a los documentos escritos en HTML. Sirve para separar el contenido (el texto y la estructura definida en HTML) de su presentación (colores, fuentes, tamaños, márgenes, etc.), permitiendo que las páginas web sean visualmente atractivas y consistentes.
